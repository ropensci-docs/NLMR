# catalog_nlm

Return a catalog of the landscape generators in NLMR.

## Usage

``` r
catalog_nlm()
```

## Value

A tibble with one row per exported landscape generator and the columns
\`algorithm\`, \`group\`, \`description\`, \`variants\`, and
\`reference\`.

## Details

The catalog is meant to help users understand the available landscape
generators.

\`nlm_curds()\` counts as two variants because it supports both random
curdling and wheyed curdling.
