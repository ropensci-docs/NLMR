# Simulating Neutral Landscape Models

*NLMR* is an R package for simulating neutral landscape models (NLMs).

## Details

This package contains vignettes that introduce NLM and basic usage of
the *NLMR* package. The vignettes in this package are listed below.

- [Quickstart
  Guide](https://docs.ropensci.org/NLMR/articles/getstarted.html):

  Short walk-through of the *NLMR* package and how to handle the
  simulations.
