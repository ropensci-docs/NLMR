# util_rescale

Linearly rescale element values in a raster to a range between 0 and 1

## Usage

``` r
util_rescale(x)
```

## Arguments

- x:

  \[`SpatRaster`\]

## Value

`SpatRaster` with each layer independently rescaled to values ranging
from 0-1. Non-missing cells in constant layers are set to 0, and
all-`NA` layers remain `NA`.

## Details

Rasters generated by `nlm_*` functions are scaled between 0 and 1 as
default, this option can be set to `FALSE` if needed.
